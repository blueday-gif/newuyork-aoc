진짜 차이가 전혀 없는 가짜 데이터를 2,195개 동네에 만들어 넣고, 동네마다 "평균과 다른가"를 검정했다. 109곳이 p < 0.05로 '유의'하게 나왔다. 검정을 많이 하면 우연이 반드시 당첨된다.

2 · 시뮬레이션으로 확인

차이가 0인 세계의 p값

동네마다 표준정규분포에서 숫자 하나(z 점수)를 뽑았다. 모든 동네의 진짜 차이는 0이다. 그리고 각 동네의 p값을 계산했다. 차이가 없는 세계에서 p값은 0과 1 사이에 고르게 퍼진다.

가짜 데이터 2,195개 동네의 p값 분포주황 = p < 0.05 칸. 막대 높이가 거의 평평하다
표로 보기

맨 왼쪽 칸(p < 0.05)에 109곳이 들어갔다. 기대값 110곳(2,195 × 5%)과 거의 같다. 이 109곳을 지도에 칠하면 "민원 이상 지역 109곳"이라는 그럴듯한 지도가 나온다. 전부 우연이다.

3 · 통계 기초 ① p값

p < 0.05가 정확히 뜻하는 것

p값은 "차이가 없다고 가정할 때, 지금만큼 큰 차이가 우연히 나올 확률"이다. p < 0.05는 "우연이라면 20번에 1번 나올 정도로 드물다"는 뜻이다. 거꾸로 말하면 20번 검정하면 1번은 우연히 통과한다. 2,195번 하면 약 110번이다.

4 · 통계 기초 ② 보정

검정이 많으면 기준을 높인다

보정 없음 (p < 0.05)109곳모두 가짜 양성
본페로니 (p < 0.05 ÷ 2,195)0곳아주 엄격하다
FDR (벤야미니-호흐베르크)0곳가짜 비율을 5%로 묶는다

본페로니는 기준을 검정 횟수로 나눈다. 2,195번이면 p < 0.0000228이어야 한다. 확실하지만 진짜 차이도 놓치기 쉽다. FDR 보정은 "유의하다고 고른 것 중 가짜의 비율"을 5% 이하로 묶는다. 덜 엄격해서 진짜 신호는 더 잘 살린다. 이 가짜 데이터에서는 두 방법 모두 0곳을 남겼다. 맞는 답이다.

이 프로젝트의 동네 군집 분석도 FDR 보정을 했고, 보정하면 국지 군집이 0개가 됐다. "보정 전 몇 곳"만 보도하면 xkcd의 초록 젤리빈이 된다.
5 · 이렇게 하면 틀린다

함정 3가지

1

보정 없이 동네 지도 칠하기. 수천 개 동네를 각각 검정해 유의한 곳만 칠하면, 우연이 만든 지도가 된다.

2

p > 0.05 = 차이 없음. 차이를 '찾지 못했다'는 뜻이다. 표본이 작으면 진짜 차이도 놓친다.

3

나중에 가설 고르기. 데이터를 다 보고 나서 "초록색이 이상하네"라고 가설을 세우면, 검정 횟수를 숨긴 것과 같다. 무엇을 검정할지 먼저 적어 둔다.

6 · 직접 해보기

파이썬으로 따라 하기

from scipy.stats import norm
from statsmodels.stats.multitest import multipletests
z = np.random.default_rng(2026).standard_normal(2195)   # 진짜 차이 = 0
p = 2 * (1 - norm.cdf(abs(z)))
(p < 0.05).sum()                                         # 약 110
multipletests(p, method="fdr_bh")[0].sum()               # 보정 뒤
